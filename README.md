# Simple Java Store

A simple console-based store simulator written in Java.

Made by **Neyzox**
Designed by **Neyzox**

## Description

This project simulates a tiny in-game-like store system: you start with a set amount of money, can choose to buy a keyboard, work to earn more money, and try to buy the keyboard again — all through simple console prompts.

It's a small learning project exploring Java basics: methods, `Scanner` input, `switch` statements, and simple program flow.

## How it works

1. The program starts with a default balance of **10€**.
2. A keyboard costs **20€**.
3. You're asked if you want to buy the keyboard right away.
4. If you don't have enough money, you're offered the chance to work (1 or 2 hours) to earn more.
5. Finally, you're asked again if you want to buy the keyboard, and the purchase goes through if you have enough money.

## Requirements

- Java JDK 8 or higher installed on your machine
- A terminal / command prompt

## Installation & How to Run

1. Clone or download this repository:

       git clone https://github.com/Neyzox123/Simple-Java-Store.git
       cd Simple-Java-Store

2. Compile the program:

       javac Main.java

3. Run the program:

       java Main

> Check `Main.java` for more info about how the program is structured — everything is commented at the top of the file.
